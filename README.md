# MedКарта — Интеллектуальная Навигация по Медицине Казани

![MedKarta Logo](https://img.shields.io/badge/MedKarta-3.0-blue?style=for-the-badge)
![Status](https://img.shields.io/badge/Status-Active-brightgreen?style=for-the-badge)

**MedКарта** — это современное веб-приложение для поиска врачей и медицинских учреждений в Казани с интеграцией искусственного интеллекта для построения сложных маршрутов.

## 🚀 Основные возможности

- **Интерактивная карта**: Наглядное отображение сотен клиник и врачей.
- **AI-Ассистент (Powered by OpenAI)**: Поиск врачей по симптомам и построение сложных маршрутов через чат.
- **Умная маршрутизация**: Поддержка до 5 точек в одном маршруте с автоматическим расчетом пути.
- **Глубокая фильтрация**: По районам, специальностям, рейтингу, стажу и услугам.
- **Темная тема**: Полная поддержка темного режима, включая стилизацию карт.
- **Мобильная адаптивность**: Удобное использование на смартфонах.

## 🛠 Технологии

- **React + Vite**
- **Tailwind CSS**
- **Leaflet & React-Leaflet** (Картография)
- **OpenRouter API (GPT-4o-mini)** (ИИ)
- **Lucide React** (Иконки)

## 📦 Установка и запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/med-navigator.git
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Создайте файл `.env` в корне проекта и добавьте ваш API ключ:
   ```env
   VITE_OPENROUTER_API_KEY=ваш_ключ
   ```
4. Запустите проект:
   ```bash
   npm run dev
   ```

## 🌐 Развертывание (Vercel)

Проект полностью готов к развертыванию на [Vercel](https://vercel.com). При импорте репозитория обязательно добавьте переменную окружения `VITE_OPENROUTER_API_KEY` в настройках проекта.
